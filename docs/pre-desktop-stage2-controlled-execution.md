# 桌面化前阶段 2：审批与受控本地执行

验收日期：2026-10-17。状态：通过阶段门禁，可进入阶段 3。阶段范围为审批、本地文本文件工具、Windows 原生命令执行与 MCP 独立调用授权。Diff、撤销及真实 worktree 属于阶段 3，正式任务和审批界面属于阶段 4。

## 交付行为

- 本地工具默认关闭。仅在可信本机部署的 `config.toml` 中设置 `[local]` 下 `enabled = true`，并通过项目接口绑定目录、在聊天请求中指定 `project_id` 后，才注入本地工具。普通聊天与已有记忆工具保持兼容，默认执行模式仍为 `original`。
- 目录授权覆盖支持的文本文件读取和编辑；删除必须逐次审批。命令默认等待审批，不因 MCP 连接配置、模型请求或工具声明而自动取得执行权限。
- 审批先持久化调用快照与 `waiting_approval` 状态，再等待独立请求作出决定。快照绑定用户、会话、项目、任务、规范化目录、执行模式、工具、权限及实际参数；命令另绑定解析后的可执行文件路径与 SHA-256。批准时校验指纹、所有权、有效期和任务状态，执行前再次校验配置、目录及命令快照。
- 拒绝、过期、撤销、取消及无效批准均不能启动对应调用。重复提交审批返回冲突，不重放工具。重启把旧运行和待处理审批标为中断，不恢复会话批准或续跑写入。
- 会话批准只复用同一会话、项目、目录下的完整相同命令快照；只允许有限的测试、版本查询和 Git 读取命令。Shell、内联代码、Git 推送、未知或破坏性命令、项目内可执行文件及目录外参数均不能获得会话批准。允许会话批准的测试命令仍可执行项目代码，批准不代表这些代码已经过安全审计。
- 会话规则仅在当前 API 进程内存中存在，可以主动撤销；撤销也使已在等待中的旧审批失效。不会把字符串前缀当成 Shell 通配权限。取消等待中的审批会清除该会话规则；已批准并开始运行的命令由取消机制停止，不承诺撤销此前产生的副作用。

## 文件工具

统一执行器注册 `builtin.local.*`；模型调用名为 `builtin__local__*`。严格 Schema 拒绝额外字段，内部准备参数不能由模型直接传入。

| 工具 | 公开参数 | 行为 |
| --- | --- | --- |
| `list` | `path`，默认 `.` | 列举一层支持的路径，返回截断标记 |
| `read` | `path` | 返回脱敏 UTF-8 文本及原始内容的 SHA-256 `version` |
| `search` | `query` | 有数量上限的项目内字面搜索，返回路径、行号与截断标记 |
| `write` | `path`、`content`、`expected_version` | 编辑需匹配读取版本；新建显式传 `null`，采用排他创建 |
| `delete` | `path`、`expected_version` | 单文件版本检查与逐次审批后删除 |
| `command` | `executable`、`args` | 在绑定目录执行明确的程序和参数数组 |

文件路径只接受使用 `/` 的项目内相对路径，父目录须已存在。支持扩展名来自 `[local].text_extensions`；默认单文件上限 1 MiB、列表/搜索结果 200 条、搜索文件数 1000。拒绝绝对路径、上跳、Windows 设备名及数据流、链接路径、硬链接、凭据目录和文件（含 `.env*`、私钥）、依赖目录及不支持的文本编码或二进制内容。

编辑保留现有 UTF-8 BOM 和一致的 CRLF 换行；在实际写入前再次验证内容版本。Windows 通过持有父目录与文件句柄保护检查和写入期间的路径身份。含可识别秘密的文件只提供脱敏读取，不能使用脱敏副本覆盖；新写入内容同样拒绝可识别秘密。脱敏依赖识别规则，不保证发现所有未知格式秘密。

当前写入不承诺崩溃原子性或自动撤销。目录互斥只约束本应用任务，用户编辑器与其他进程仍可能修改文件；版本冲突时拒绝覆盖。

## 审批接口

沿用现有演示鉴权与 `user_key` 用户域。`user_key` 不是身份认证，尚不能将本机执行服务开放到公网；本地访问安全仍需阶段 7 完成。

| 方法与路径 | 行为 |
| --- | --- |
| `GET /v1/approvals?user_key=...&run_id=...` | 查询所属用户的待处理审批，最多 100 条；返回绑定快照、指纹、到期时间、风险说明及 `session_allowed` |
| `POST /v1/approvals/{id}/decision?user_key=...` | 提交查询所得指纹与 `approve_once`、`approve_session` 或 `reject` |
| `POST /v1/approvals/revoke?user_key=...` | 请求体为 `{"conversation_id":"会话 UUID"}`，撤销该会话的内存批准规则 |
| `POST /v1/runs/{id}/cancel?user_key=...` | 沿用阶段 1 取消入口，停止审批等待或正在执行的任务 |

审批请求体示例（指纹必须原样使用实际查询结果）：

```json
{
  "fingerprint": "查询结果中的64位SHA-256指纹",
  "decision": "approve_once"
}
```

决定接口不接收替换命令或参数。错误用户返回 404；过期、重复决定、指纹不符及不允许的会话批准返回 409。`approval.requested`、`approval.resolved` 和 `approval.rule_used` 写入运行事件，重新查询待处理审批可以恢复展示。正式界面尚未接入，当前通过接口与自动化测试验收。

## 命令与 MCP

命令不隐式解析 Shell，脚本需要显式解释器。工作目录固定为任务绑定目录，PATH 名称解析排除项目目录；审批后的可执行文件内容变化使批准失效。子进程只继承必要的系统、路径、临时目录及语言环境，排除应用提供商密钥、数据库凭据和 `PYTHONPATH`。

Windows 使用挂起创建进程、加入带关闭终止策略的 Job Object 后恢复运行，显式限制继承句柄。命令超时、用户取消、应用关闭以及主进程正常退出都会回收其子进程树。后台读取持续排空管道，保留受限且脱敏的 stdout/stderr；默认合计输出上限 64 KiB、命令超时 60 秒、审批有效期 120 秒，阈值在 `[local]` 配置。非零退出和超时保留退出码、输出、截断标记及失败信息，写入工具审计，也返回给模型用于修正。

MCP 连接配置中的能力不再自动变成当前请求权限。Agent 与 legacy HTTP 的远程工具调用进入同一审批与运行控制机制；仅连接服务不代表批准每次调用。原有 legacy 内置记忆兼容路径保留，不新增标准 MCP 服务端。

这些命令以本机用户权限运行，可以访问目录外资源或网络。路径检查、环境清理、审批和 Job Object 都不是操作系统级沙箱；已完成的文件、网络或其他外部副作用不会因终止进程而自动撤销。

## 模块与迁移

- `app/permission/approvals.py`：调用绑定、持久化等待、一次性决定、会话规则与撤销。
- `app/api/approvals.py`、`app/persistence/approvals.py`：用户域查询、决定接口与审批记录。
- `app/tools/local`：参数 Schema、路径与文件版本校验、文件句柄保护及命令准备。
- `app/execution/process.py`、`windows_process.py`：输出采集、超时/取消和原生进程树生命周期；`remote_call.py` 负责 legacy 远程工具运行接入。
- `app/security/tool_secrets.py`：审批参数中的敏感字段与命令凭据识别；复用统一输出脱敏。
- `0009_tool_approvals`：审批表、所属用户/任务关联及状态记录。回退会删除审批表，实际数据回退前须备份。
